# JGA Enterprises — John Arenz

Building something from nothing. Self-taught systems builder in Peoria, Illinois.

## What I build

### Jay's Graphic Arts (Brick 1)
AI-assisted graphic design — logos, brand kits, CD covers, posters, flyers, business cards, event tickets, social graphics. Fully automated pipeline with human approval gates: request → design → proof → approval → delivery. Clean files are delivered only after final payment and client approval.

🔗 Live store: https://jays-graphic-arts.onrender.com

### Talent Agent Plus
A tool for independent artists to find opportunities, book gigs, collect cleared payments, and communicate — with approval gates at every step. Flat software pricing, not commission. Tiers: Try free, Starter, Pro, Full Label. It is a discovery and bookkeeping tool, not a licensed talent agency.

🔗 Live app: https://talent-agent-plus.onrender.com

### AVA — Artificial Virtual Assistant
The assistant at the heart of JGA. One unified system with shared memory, living in the Stitch. She runs the design pipeline, the artist tools, and the owner's room.

### BCT — Braided Computational Topology
The integrity architecture underneath it all: hash-linked evidence chains, admission and identity key-binding, and a knowledge braid across domains. Research code lives in the repos below.
